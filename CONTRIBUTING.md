# Contributing

1. `npm install`, then `npm run hooks` to check for personal data before every commit.
2. Keep it small: plain Node, one dependency, no build step.
3. Add a test for any rule. `npm test` must pass, and new visible text needs its line in `locales/es.json`.
4. Use made-up people, companies and addresses (`example.com`, `555-01xx`).

Changes that bypass a bot check, a CAPTCHA, a sign-in or a site's terms are not accepted.
